# Open Banking Angola 🇦🇴

Bem-vindo à comunidade e ecossistema de código aberto para o **Open Banking & Open Finance em Angola**, mantido pela **Vanguard IT**.

O nosso objetivo é disponibilizar padrões de APIs, arquiteturas de segurança de nível financeiro (FAPI) e ferramentas de desenvolvimento que acelerem a adoção e a interoperabilidade do ecossistema financeiro angolano.

---

## 🚀 Projetos em Destaque

- 📘 [openbanking-ao-specs](./openbanking-ao-specs): Especificações OpenAPI (Swagger) adaptadas ao mercado angolano.
- 🧪 [openbanking-mock-server](./openbanking-mock-server): Ambiente Sandbox local em Docker para testes de integração de APIs.
- 🔐 [fapi-security-guide](./fapi-security-guide): Guia prático de implementação de OAuth2, mTLS e FAPI no sector bancário.
- 📦 [openbanking-sdk-ts](./openbanking-sdk-ts): SDK em TypeScript/Node.js para integração com APIs de Open Banking.
